# Ek Unit (एक यूनिट) – Team Vanta
**The Code Vibes Hackathon 2.0 · Track: Open Innovation (Sustainable Development / Social Impact)**

> Find the one unit that costs you the most.

## Problem
Indian household electricity bills use slab-based tariffs. Many families sit just under a slab edge without knowing it. In whole-slab billing, a single extra unit can raise the rate on every unit. Bills don't explain this, spikes from faulty meters are hard to prove, and most people can't tell whether rooftop solar would pay off.

## Solution
Ek Unit is a bill detective that runs in the browser with no sign-up:
- **Slab ladder:** shows your slab, units left before the rate jumps, and the exact cost of crossing it (telescopic and whole-slab billing supported).
- **Appliance breakdown:** estimates which appliances explain your units and flags the unexplained gap.
- **Spike check:** compares this month with your history using mean and standard deviation, and generates a meter-test complaint letter.
- **Solar payback:** estimates out-of-pocket cost and payback under the PM Surya Ghar subsidy.

## Tech stack
HTML, CSS, vanilla JavaScript (single file, no dependencies, works offline). Google Fonts optional.

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Note
Tariff values are editable demo numbers, not any utility's official rates. Edit them in the Tariff section to match your bill.

## Business model
- Solar installers pay per qualified lead.
- Discoms license it to reduce billing disputes.
- RWAs and housing societies pay a subscription.

## Future scope
Bill photo OCR, Hindi and regional languages, smart-meter data import, state-wise tariff database, WhatsApp bot.
